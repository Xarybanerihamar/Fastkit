FASTKIT PACKAGING WEBSITE
=========================

Pages:
- index.html — Home
- capabilities.html — Capabilities / services
- contact.html — Contact form

Domain used in metadata and footer:
- fastkitpckg.com

Important:
- No phone number is included anywhere.
- No email address is included anywhere.
- The contact form is currently front-end only. It validates required fields and shows a green success confirmation, but it does NOT transmit form data anywhere yet.
- Once you choose the business email / form service / hosting method, connect the form in assets/main.js or to a form endpoint.

GitHub Pages:
1. Upload the contents of this folder to the repository root.
2. Enable GitHub Pages from the main branch/root folder.
3. Test the GitHub Pages URL first.
4. After testing, connect fastkitpckg.com in GitHub Pages and configure DNS.

No CNAME file is included intentionally, so uploading the site will not automatically attach the custom domain before you test it.
